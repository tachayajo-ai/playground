# playground

พื้นที่ทำของสนุก ๆ ไม่เกี่ยวกับงาน

## kiddo-talk/

แอปฝึกภาษาอังกฤษสำหรับพ่อแม่ เพื่อใช้พูดกับลูกวัย 4–7 ขวบในชีวิตประจำวัน

- **วันนี้**: ประโยคของวันตามช่วงเวลา และความคืบหน้า
- **พูดกับลูก**: 79 ประโยค เรียงตามกิจวัตร (ตื่นนอน → ก่อนนอน) และหมวดที่ใช้ได้ทั้งวัน (ชมเชย ความรู้สึก กติกา)
- **Grammar**: 11 บทที่ใช้บ่อยในบ้าน พร้อมจุดที่คนไทยพูดผิดบ่อยและแบบทดสอบ
- **ฝึกพูด**: แสดงประโยคภาษาไทย ให้พูดเป็นภาษาอังกฤษ แล้วเทียบกับเฉลยทีละคำ (ใช้ไมค์ได้ใน Chrome)

`app.html` คือต้นฉบับ ถ้าแก้ไฟล์นี้ให้รัน `./build.sh` เพื่อสร้าง `index.html` ใหม่ (เปิดในเบราว์เซอร์ได้เลย หรือเปิด GitHub Pages)

## grammar-lab/

Grammar สำหรับเตรียมสอบ (TOEIC Part 5–6, CU-TEP, TU-GET, ภาษาอังกฤษ ก.พ.)

- ตำรา 15 บท แบ่ง 5 Part ตั้งแต่โครงสร้างประโยคพื้นฐานถึง Inversion/Subjunctive/Causative รวมกว่า 200 หัวข้อย่อย
- ทุกบทมีสารบัญ คำอธิบายภาษาไทย ตารางกฎ ตัวอย่างที่แยกส่วนประโยค S/V/O/C/A ด้วยสี กับดักในข้อสอบ และสรุปท้ายบท
- แบบฝึกหัด 908 ข้อ แบ่งเป็นชุดย่อยทุกบท (เติมคำ หาจุดผิด และแบบฝึกพื้นฐาน)
- ข้อสอบจำลอง: สุ่มจากคลัง 792 ข้อ (ไม่รวมแบบฝึกพื้นฐาน) จับเวลา เฉลยพร้อมคำอธิบาย และบอกบทที่ควรทบทวน
- TOEIC Part 6: เนื้อเรื่อง 28 เรื่อง (อีเมล บันทึก ประกาศ จดหมาย) เรื่องละ 4 ข้อ รวม 112 ข้อ มีข้อคำศัพท์ 33 ข้อ และข้อเลือกประโยคแทรก 28 ข้อ ฝึกทีละเรื่อง หรือชุดจำลอง 4 เรื่องแบบจับเวลา
- โหมดทบทวน: ข้อที่เคยตอบผิดจะอยู่ในรายการจนกว่าจะตอบถูกติดกัน 2 ครั้ง ทำทีละข้อ เฉลยทันที เลือกทั้งหมดหรือรายบทได้
- สถิติรายบท และจุดอ่อน 3 อันดับแรก

## jam-escape/

หนีรถติด: เกมปริศนาเลื่อนรถ 6×6 เล่นคนเดียว ออฟไลน์ (ไฟล์ `index.html` ไฟล์เดียว)

- ลากรถให้เปิดทางรถสีแดงออกประตูด้านขวา 40 ด่าน 5 ระดับ (3–37 ตา) ทุกด่านตรวจด้วย solver ว่าจำนวนตาขั้นต่ำถูกต้อง
- บอท (BFS) ให้คำใบ้ตาถัดไป เล่นให้ดูด้วยทางที่สั้นที่สุด บอกจำนวนตาที่เหลือ และสุ่มสร้างด่านใหม่ 3 ระดับ
- ดาว 1–3 ตามจำนวนตาที่ใช้ เก็บสถิติไว้ในเบราว์เซอร์ สลับธีมสว่าง/มืดได้

## beach-volley/

ตบชายหาด: วอลเลย์บอลชายหาด 1 ต่อ 1 กับบอท เล่นบนมือถือได้ ออฟไลน์ (ไฟล์ `index.html` ไฟล์เดียว)

- ตัวละครออกแบบเอง 3 ตัว (แมวส้ม เพนกวิน กระต่าย) ฉากชายหาดมีคลื่น เมฆ นก ต้นมะพร้าวไหว
- จอยสติ๊กเลื่อนซ้าย-ขวา (ลอยตามจุดที่แตะ ลากไกลวิ่งเร็ว) + ปุ่ม ▲ กระโดด ⚡ ตบ (แนวนอนลอยบนสนาม แนวตั้งอยู่ใต้สนาม) หรือคีย์บอร์ด
- ลูกที่ลอยพ้นขอบจอบน มีป้ายลูกบอล + ลูกศรที่ขอบบนบอกจุดที่จะตกลงมา (สีตามฝั่ง ใหญ่ขึ้นเมื่อใกล้)
- กระโดดตบ 3 แบบตามทิศที่กด (พุ่งแรง / ปักลง / หยอด) ลูกตบคำนวณให้ข้ามเน็ตเสมอ
- บอท 3 ระดับ ทำนายจุดตกของลูกล่วงหน้า ทดสอบบอทแข่งกันแล้ว: โปรชนะชิลล์ ~80% ของแต้ม
- เล่นถึง 7 / 11 / 15 แต้ม (ต้องนำ 2) เสียงสังเคราะห์ด้วย WebAudio ปิดได้

## star-storm/

พายุดารา: เกมยิงยานอวกาศแนวตั้ง 3 ด่าน เล่นบนมือถือได้ ออฟไลน์ (ไฟล์ `index.html` ไฟล์เดียว)

- กราฟิกสไตล์ Famicom: วาดที่ 180×320 แล้วขยายแบบพิกเซลคม สไปรต์พิกเซลวาดเอง สีจากพาเลต NES ใช้กะพริบ/ดิทเทอร์แทนความโปร่งใส เสียง pulse/triangle/noise + เพลง chiptune แต่งเอง (ด่าน/บอส)

- เปิดเกม: หน้าชื่อเกมโลโก้พิกเซล (แถบสี NES ขอบ เงา แสงวาบ) → แตะ → เนื้อเรื่องวิ่งขึ้นแบบเปอร์สเปคทีฟพร้อมเพลงเปิด → แตะอีกครั้งเข้าเกม
- เอเลี่ยน 3 แบบ (ตัวเขียวเข้าแถวแล้วพุ่งโจมตี ตัวแมลงบินซิกแซก ปูหุ้มเกราะยิงกระจาย) 5 ระลอก แล้วเจอบอส "ราชินีโคลอส" สัตว์ประหลาดมีเขา 3 ตา อ้าปากโชว์ฟันตอนยิง แขนก้ามหนีบ คำรามตอนเข้าฉาก/เปลี่ยนช่วง 3 ช่วง (กระสุนพัด → วงแหวน + เรียกลูกสมุน → กระสุนเกลียว + เลเซอร์มีเส้นเตือนก่อนยิง)
- ไอเท็ม: ♥ เพิ่มชีวิต (สูงสุด 5) · ⬢ เกราะกันกระสุน (สูงสุด 3 ชั้น โดนแล้วลบกระสุนรอบตัว) · P อัปปืน 5 ขั้น (ขั้น 4–5 มีมิสไซล์นำวิถี) และแจกไอเท็มท้ายทุกระลอก
- ยานมีสไปรต์เอียงซ้าย/ขวา ไอพ่นยาวขึ้นตอนพุ่ง เงากะพริบตามหลัง/เส้นความเร็วตอนเคลื่อนเร็ว ไฟปลายปีกกะพริบ จอสั่น/แฟลชตอนระเบิด
- ด่าน 2 "ป้อมดาวเหล็ก": ฉากหลังเป็นป้อมอวกาศเลื่อนลงตลอด (แผ่นเหล็ก โรงจอด ช่องระบาย ไฟกะพริบ) ศัตรูใหม่: ป้อมปืนติดผิวป้อมเลื่อนตามฉาก + เครื่องบินขับไล่บินเป็นรูปตัว V · บอส "เรือธงเดรดนอต" เรือรบยักษ์: ยิงป้อมปืนข้างลำ 2 ป้อมเพื่อเปิดเกราะเตาปฏิกรณ์ (ก่อนหน้านั้นแกนกลางรับดาเมจ 30%) มีจรวดนำวิถี ปืนใหญ่หัวเรือชาร์จแล้วยิงลำแสง และกระสุนเกลียว 3 แขนตอนวิกฤต
- ด่าน 3 "ดาวรังโคลอส": อุโมงค์เนื้อเยื่อมีชีวิตเลื่อนลง (ผนังชมพูม่วง เส้นเลือด ไข่เรืองแสง) ศัตรูใหม่: ฝักสปอร์ (แตกแล้วกระจายกระสุนเป็นวง) + หนอนยักษ์ลำตัวเป็นปล้อง (ยิงโดนตรงไหนก็ได้ แต่ชนลำตัวเจ็บ) · บอสสุดท้าย "หัวใจรัง": สมองหัวใจยักษ์ตาเดียว ลูกแก้ว 6 ลูกโคจรกันกระสุน (แตกแล้วงอกใหม่) ลำแสงคู่กวาด เรียกสปอร์/หนอน ช่วงสุดท้ายลูกแก้วแตกหมด กระสุนวงแหวนสลับ · เพลงด่าน/บอสสุดท้ายแต่งใหม่
- ผ่านด่าน 1 → ปุ่ม "▶ ด่าน 2" (หัวใจ เกราะ ปืน คะแนนติดตัวไป) + เนื้อเรื่องตอนที่ 2 (ด่าน 2 → 3 แบบเดียวกัน) · ปลดล็อกแล้วเลือกด่านได้จากหน้าชื่อเกม (เริ่มด่าน 2 ด้วยปืนขั้น 3, ด่าน 3 ขั้น 4) · ฉากด่าน 1 ก็เลื่อนช้า ๆ
- มือถือ: ลากนิ้วแบบสัมพัทธ์ (นิ้วไม่บังยาน) ยิงอัตโนมัติ · คีย์บอร์ด: ลูกศร/WASD
- หลังตาย: หน้า CONTINUE นับถอยหลัง 10 วิ เล่นต่อได้ 3 ครั้ง เกิดใหม่ตรงจุดเดิม (บอสเลือดเท่าเดิม) พร้อม ♥3 เกราะ 1 ชั้น อมตะชั่วคราว ปืนไม่ต่ำกว่าขั้น 2

## house-plan/

แปลนบ้าน: โปรแกรมเขียนแปลนบ้าน 2 มิติ เน้นใช้บนแท็บเล็ต ออฟไลน์ (ไฟล์ `index.html` ไฟล์เดียว)

- วาดห้องสี่เหลี่ยมหรือรูปทรงอิสระบนตารางเมตร จับตารางและแนวผนังห้องข้างเคียงอัตโนมัติ ขึ้นขนาดและพื้นที่ (ตร.ม.) ทันที
- ประตู (บานเปิด บานคู่ บานเลื่อน ช่องเปิด) และหน้าต่างจับเข้าผนังเอง เฟอร์นิเจอร์ 23 แบบชิดผนังเอง หมุนและปรับขนาดได้
- หลายชั้น: ชั้นบนเห็นเส้นประของชั้นล่าง คัดลอกชั้นได้ สรุปพื้นที่รายห้อง รายชั้น ทั้งหลัง และสัดส่วนอาคารต่อที่ดิน (ตร.ม./ตร.ว.)
- ✦ สร้างแปลนอัตโนมัติจากขนาดที่ดิน ระยะร่น จำนวนชั้น ห้องนอน ห้องน้ำ และที่จอดรถ (ทำงานในเครื่อง)
- ↔ ย้ายบ้านทั้งหลัง: ลากบนแปลน ปุ่มลูกศร จัดกึ่งกลาง หรือพิมพ์ระยะจากแนวเขตที่ดินทั้ง 4 ด้าน (ทุกชั้นย้ายพร้อมกัน)
- ห้องผู้สูงอายุ/วีลแชร์ (♿): ตรวจประตูกว้าง ≥ 0.90 ม. ที่ว่างหมุนวีลแชร์ Ø 1.50 ม. ประตูห้องน้ำเปิดออกหรือบานเลื่อน และราวจับ พร้อมปุ่มปรับห้องให้ผ่านเกณฑ์
- นำเข้าแปลนจาก AI: คัดลอกคำสั่งไปถาม Claude แล้ววาง JSON ที่ได้กลับมา
- สองนิ้วซูม/เลื่อน ถ้าใช้ Apple Pencil ปากกาจะวาด นิ้วจะเลื่อนจอ บันทึกอัตโนมัติ ส่งออก PNG พิมพ์/PDF และบันทึกเป็นไฟล์ .json
- 🧊 มุมมอง 3 มิติ (WebGL เขียนเอง ไม่ต้องใช้เน็ต): ผนังเจาะช่องประตู/หน้าต่าง บานประตู กระจก บันไดขึ้นชั้นบน เฟอร์นิเจอร์ หลังคา 4 แบบ (ปั้นหยา จั่ว หมาแหงน แบน/ดาดฟ้า) ปรับความชัน หมุนแนวสัน เลือกสี เติมจั่วส่วนชั้นล่างที่ชั้นบนไม่คลุมอัตโนมัติ สีพื้น/ผนังรายห้อง (แตะห้องใน 3D ได้) สีผนังภายนอก เลือกแสดงทีละชั้น ตัดผนังเตี้ยเพื่อดูภายใน ปรับความสูงชั้น และบันทึกภาพ
- 📐 ตรวจแบบ/BOQ: วางเสา-คานอัตโนมัติ (ช่วงเสา ≤ 4 ม.) ตรวจเสาลอย ส่วนยื่น ผนังที่ไม่มีคานรับ ช่วงพื้น บันได ระยะดิ่ง ช่องเปิด 10% ระยะร่น ที่ว่าง 30% แสดงจุดบนแปลน และ BOQ ถอดปริมาณทุกหมวด แก้ราคาต่อหน่วยได้ ส่งออก CSV/พิมพ์ (ราคาตั้งต้นเป็นค่าประมาณ ต้องปรับเอง)

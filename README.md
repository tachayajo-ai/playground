## kiddo-talk/

แอปฝึกภาษาอังกฤษสำหรับพ่อแม่ เพื่อใช้พูดกับลูกวัย 4–7 ขวบในชีวิตประจำวัน

- **วันนี้**: ประโยคของวันตามช่วงเวลา และความคืบหน้า
- **พูดกับลูก**: 79 ประโยค เรียงตามกิจวัตร (ตื่นนอน → ก่อนนอน) และหมวดที่ใช้ได้ทั้งวัน (ชมเชย ความรู้สึก กติกา)
- **Grammar**: 11 บทที่ใช้บ่อยในบ้าน พร้อมจุดที่คนไทยพูดผิดบ่อยและแบบทดสอบ
- **ฝึกพูด**: แสดงประโยคภาษาไทย ให้พูดเป็นภาษาอังกฤษ แล้วเทียบกับเฉลยทีละคำ (ใช้ไมค์ได้ใน Chrome)

`app.html` คือต้นฉบับ ถ้าแก้ไฟล์นี้ให้รัน `./build.sh` เพื่อสร้าง `index.html` ใหม่ (เปิดในเบราว์เซอร์ได้เลย หรือเปิด GitHub Pages)

## grammar-lab/

Grammar สำหรับเตรียมสอบ (TOEIC Part 5–6, CU-TEP, TU-GET, ภาษาอังกฤษ ก.พ.)

- ตำรา 15 บท แบ่ง 5 Part ตั้งแต่โครงสร้างประโยคพื้นฐานถึง Inversion/Subjunctive/Causative รวมกว่า 200 หัวข้อย่อย
- ทุกบทมีสารบัญ คำอธิบายภาษาไทย ตารางกฎ ตัวอย่างที่แยกส่วนประโยค S/V/O/C/A ด้วยสี กับดักในข้อสอบ และสรุปท้ายบท
- แบบฝึกหัด 908 ข้อ แบ่งเป็นชุดย่อยทุกบท (เติมคำ หาจุดผิด และแบบฝึกพื้นฐาน)
- ข้อสอบจำลอง: สุ่มจากคลัง 792 ข้อ (ไม่รวมแบบฝึกพื้นฐาน) จับเวลา เฉลยพร้อมคำอธิบาย และบอกบทที่ควรทบทวน
- TOEIC Part 6: เนื้อเรื่อง 10 เรื่อง (อีเมล บันทึก ประกาศ จดหมาย) เรื่องละ 4 ข้อ รวมข้อเลือกประโยคแทรก ฝึกทีละเรื่อง หรือชุดจำลอง 4 เรื่องแบบจับเวลา
- โหมดทบทวน: ข้อที่เคยตอบผิดจะอยู่ในรายการจนกว่าจะตอบถูกติดกัน 2 ครั้ง ทำทีละข้อ เฉลยทันที เลือกทั้งหมดหรือรายบทได้
- สถิติรายบท และจุดอ่อน 3 อันดับแรก
